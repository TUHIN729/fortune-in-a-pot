A single kind, funny fortune for the houseplant on the windowsill, written for the make.fun competition "Fortune in a Pot": the sun is saving its best light for the plant's newest leaf, and by Friday even the cat will envy its spot on the sill. The program is deterministic — it writes exactly that one line to `/output/entry.txt` on every run, with no randomness, no network, and no model call.

## Run it

```sh
node main.ts
```
